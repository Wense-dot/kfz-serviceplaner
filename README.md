# Kfz-Serviceplaner iOS Build Anleitung

1. Node.js installieren: https://nodejs.org/
2. Ordner entpacken & im Terminal / CMD öffnen:
   npm install
3. Auf GitHub.com ein neues Repository anlegen und Dateien hochladen.
4. Bei Ionic Appflow (https://ionicframework.com/appflow) mit GitHub anmelden.
5. "New Build -> iOS" wählen. Das fertige Paket zum Download erhalten!
